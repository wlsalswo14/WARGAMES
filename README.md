# PROJECT BRICK WARFARE

플레이어의 명령 패턴을 학습하는 적 지휘 AI를 속이고, 결정적인 순간 유닛에 직접 접속하는 3D 블록 전술 게임입니다.

> **현재 상태:** 브라우저 플레이가 가능한 기술 데모  
> **플레이 링크:** `https://wlsalswo14.github.io/WARGAMES/`
> **1:1:1 바로 시작:** `https://wlsalswo14.github.io/WARGAMES/?mode=challenge&factions=3`
> **Sandbox:** `https://wlsalswo14.github.io/WARGAMES/?mode=sandbox`

## 핵심 기능

- **AI Challenge:** 7분짜리 `1:1` 또는 `1:1:1` 점수전을 선택합니다. 진영별 시작 거점 3개와 중앙 중립 거점 3개를 두고 경쟁합니다.
- **Adaptive Commander:** 플레이어가 반복해서 명령하는 거점을 확률적으로 예측하고 적월 예비대를 해당 전선에 집중합니다.
- **Deception Bonus:** 높은 확률로 예측된 목표와 다른 거점으로 공세를 전환하면 AI 기만 보너스와 추가 점수를 얻습니다.
- **Limited Command Economy:** 병력·장벽·대형 건물 배치에 SUP가 필요하며, 동시 운용 병력과 발사체 수를 제한합니다.
- **Tactical Possession Link:** 청람 유닛을 15초 동안 직접 조종할 수 있고, 사용 후 45초 동안 링크가 재충전됩니다.
- **Real-Scale City:** 10층 이상 규모의 고층 블록 건물과 긴 방벽으로 엄폐·병목·우회로가 생기는 수제 시가전을 제공합니다.
- **Sandbox Preserved:** `?mode=sandbox`에서는 기존 3개 진영, 무한 배치, 지형 제작, 랜덤 절차적 전장을 그대로 사용할 수 있습니다.
- **Invisible Spectator:** 피해를 받지 않는 투명 자유 관찰자로 전장을 비행하며 병력·지형을 배치하고 명령합니다.
- **Last-Army Survival:** 각 진영은 기본 병력 18기로 시작합니다. 병력이 남아 있으면 거점을 다시 점령해 증원을 재개할 수 있고, 생존 병력이 0명이 되는 순간 멸망합니다.
- **Unlimited Deployment:** 신 모드에서는 보급 비용 없이 모든 진영의 유닛과 방어물을 무한 배치합니다.
- **Terrain Creator:** 신 모드에서 산과 참호뿐 아니라 고층 건물, 긴 장벽과 나무를 원하는 위치에 생성합니다.
- **Unit Possession:** 아군·중립·적군 구분 없이 보병, 전차, 전투기, 헬기, 드론을 직접 조종합니다.
- **Random Battlefield Themes:** 실행할 때마다 산악·참호·시가·삼림·협곡·강변 6개 전장 중 하나를 선택하고 고층 건물과 장벽을 다른 위치에 생성합니다.
- **Procedural Battlefield:** 카메라 이동에 따라 지형과 숲이 청크 단위로 계속 생성됩니다.
- **Outpost Warfare:** 17개 거점을 점령할수록 진영색 영토, 보급 수입, 분산 증원 위치가 확장됩니다.
- **Straight-Line Weapons:** 일반탄과 특수탄은 조준 방향으로 직선 비행하며 장갑 방향과 입사각에 따라 관통·도탄을 계산합니다.
- **Dual Weapons:** 보병을 제외한 유닛은 빠른 일반공격과 느리지만 건물을 일격 파괴하는 특수공격을 사용하며, 드론은 특수공격으로 자폭합니다.
- **Visible Tracers:** 소총탄·기관포탄·전차 포탄을 병과별 크기와 길이가 다른 밝은 트레이서로 표시합니다.
- **Vehicle & Flight Dynamics:** 전차 관성, 참호 기동 제한, 전투기 양력·실속, 헬기 지면효과·와류고리, 드론 측풍을 반영합니다.
- **Aircraft Collisions:** 전투기와 헬기는 지형, 나무, 건물, 거점 또는 다른 유닛과 충돌하면 즉시 폭발합니다.
- **Structure Collisions:** 지상 유닛과 드론은 건물·장벽을 통과하지 못하며 충돌 시 벽면을 따라 이동합니다.
- **Brick Destruction:** 개별 블록에 피해를 주며 하부 지지 블록이 무너지면 상부가 연쇄 붕괴합니다.
- **Cinematic Kill Camera:** Sandbox에서 플레이어의 격파와 빙의 유닛 사망을 감지해 브릭 폭발을 확대합니다.
- **Autonomous Diplomacy:** 3개 AI 진영이 전력 균형에 따라 동맹·중립·적대를 자율 변경합니다.
- **AI Commander:** 각 진영 지휘관이 거점과 병력 구성을 분석해 돌파·점령·방어·항공 우세 작전을 선택합니다.

## 조작 방법

### 신 모드

| 조작 | 기능 |
| --- | --- |
| `W` / `S` | 관찰 시선 방향으로 전진·후진 |
| `A` / `D` | 좌우 이동 |
| `Space` / `Shift` | 관찰자 상승·하강 |
| `Q` / `E` | 카메라 회전 |
| 마우스 휠 | 관찰자 이동속도 조절 |
| 전장 시작 | 별도 클릭 없이 마우스 포인터 자동 고정 |
| 화면 클릭 | `Esc`로 해제한 마우스 포인터 다시 고정 |
| 마우스 이동 | 마우스가 움직이는 방향으로 자유 시점 전환 |
| `Esc` | 마우스 포인터 고정 해제 |
| 좌클릭 | 유닛 선택 또는 병력 배치 |
| 우클릭 | 선택 유닛 이동·공격 명령 |
| 더블클릭 / `Enter` | 선택 유닛 직접 조종 |
| `F` | Sandbox 배치 진영 변경 |
| `1`~`9`, `0` | 유닛·방어물·산·참호·건물·나무 선택 |

| 조작 | 기능 |

| `G` / `Esc` | 신 모드 복귀 |

## 로컬 실행

Node.js 24 이상을 권장합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run check
npm run build
npm run preview
```

## 기술 구성

- TypeScript
- Three.js
- Vite
- WebGL
- GitHub Actions / GitHub Pages

외부 이미지·3D 모델·사운드 에셋을 사용하지 않습니다. 화면에 표시되는 유닛, 블록, 지형, 식생 및 효과는 모두 런타임 코드에서 기본 지오메트리로 생성됩니다.

## 프로젝트 구조

```text
src/
├─ game/
│  ├─ battlefield/    # 전장 배치 데이터와 기본 병력 편성
│  ├─ entities/       # 유닛, 발사체, 거점, 파괴 구조물
│  ├─ input/          # 키보드·마우스·포인터 잠금 입력
│  ├─ modes/          # Challenge/Sandbox 규칙과 밸런스
│  ├─ systems/        # 전투, 적응형 AI, 세션, 외교
│  ├─ ui/             # HUD와 조작 UI
│  ├─ world/          # 절차 생성 지형
│  └─ BrickWarfare.ts # 모듈을 조율하는 메인 게임 루프
└─ main.ts
```

## 성능 기준

- Challenge 동시 활성 유닛 기본 24개, 진영별 기본 12기·최대 16기 운용
- 파괴된 유닛은 연출 후 씬과 AI 탐색 목록에서 자동 정리
- 렌더 루프는 최대 60 FPS, Challenge AI 이동은 20 Hz, HUD 갱신은 5 Hz로 제한
- 건물의 개별 브릭을 재질별 `InstancedMesh`로 묶어 드로우콜 절감
- Challenge 발사체 최대 72개, 구조물별 잔해 최대 90개
- Challenge 절차 지형 반경 5×5 청크, Sandbox 7×7 청크
- 10층 이상 고층 건물은 상세 동적 그림자를 자동 생략하고 수신 그림자는 유지
- 렌더 픽셀 비율과 그림자 해상도를 제한하고 소프트웨어 렌더링 감지 시 경고
