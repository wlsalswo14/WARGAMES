# PROJECT BRICK WARFARE

블록으로 구성된 무한 전장을 지휘하고, 전장에 존재하는 모든 진영의 유닛을 직접 조종하는 3D 샌드박스 전쟁 시뮬레이터입니다.

> **현재 상태:** 브라우저 플레이가 가능한 기술 데모  
> **플레이 링크:** `https://wlsalswo14.github.io/wargames/`

## 핵심 기능

- **God Eye View:** 전장을 관망하며 병력·장벽·참호를 배치하고 이동 명령을 내립니다.
- **Unit Possession:** 아군·중립·적군 구분 없이 보병, 전차, 전투기, 헬기, 드론을 직접 조종합니다.
- **Procedural Battlefield:** 카메라 이동에 따라 지형과 숲이 청크 단위로 계속 생성됩니다.
- **Outpost Warfare:** 거점을 점령하면 해당 진영의 보급 수입과 증원 위치가 확장됩니다.
- **Ballistics & Armor:** 탄환 이동 시간, 중력 낙차, 측풍, 장갑 방향, 입사각 도탄을 계산합니다.
- **Vehicle & Flight Dynamics:** 전차 관성, 참호 기동 제한, 전투기 양력·실속, 헬기 지면효과·와류고리, 드론 측풍을 반영합니다.
- **Brick Destruction:** 개별 블록에 피해를 주며 하부 지지 블록이 무너지면 상부가 연쇄 붕괴합니다.
- **Autonomous Diplomacy:** 3개 AI 진영이 전력 균형에 따라 동맹·중립·적대를 자율 변경합니다.
- **AI Commander:** 각 진영 지휘관이 거점과 병력 구성을 분석해 돌파·점령·방어·항공 우세 작전을 선택합니다.

## 조작 방법

### 신 모드

| 조작 | 기능 |
| --- | --- |
| `WASD` | 카메라 이동 |
| `Q` / `E` | 카메라 회전 |
| 마우스 휠 | 확대·축소 |
| 좌클릭 | 유닛 선택 또는 병력 배치 |
| 우클릭 | 선택 유닛 이동·공격 명령 |
| 더블클릭 / `Enter` | 선택 유닛 직접 조종 |
| `F` | 배치 진영 변경 |
| `1`~`7` | 배치 종류 선택 |

### 직접 조종

| 조작 | 기능 |
| --- | --- |
| `WASD` | 이동·조향·추력 |
| 마우스 | 조준과 시점 |
| 좌클릭 | 주무기 발사 |
| `Space` / `Ctrl` | 항공 유닛 상승·하강 또는 기수 조작 |
| `V` | 1인칭·3인칭 전환 |
| `G` / `Esc` | 신 모드 복귀 |

## 로컬 실행

Node.js 24 이상을 권장합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run check
npm run build
npm run preview
```

## 기술 구성

- TypeScript
- Three.js
- Vite
- WebGL
- GitHub Actions / GitHub Pages

외부 이미지·3D 모델·사운드 에셋을 사용하지 않습니다. 화면에 표시되는 유닛, 블록, 지형, 식생 및 효과는 모두 런타임 코드에서 기본 지오메트리로 생성됩니다.

## 프로젝트 구조

```text
src/
├─ game/
│  ├─ entities/       # 유닛, 발사체, 거점, 파괴 구조물
│  ├─ systems/        # 전투, 진영 AI, 외교
│  ├─ ui/             # HUD와 조작 UI
│  ├─ world/          # 절차 생성 지형
│  └─ BrickWarfare.ts # 메인 게임 루프
└─ main.ts
```

## 성능 기준

- 동시 활성 유닛 기본 27개, 진영별 최대 16개
- 발사체 최대 180개
- 브릭 파편 최대 220개
- 절차 지형 반경 7×7 청크
- 기기 해상도에 따라 최대 렌더 픽셀 비율 제한
