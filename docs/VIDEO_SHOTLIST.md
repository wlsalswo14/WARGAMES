# 30초 플레이 영상 구성

## 촬영 원칙

- 실제 브라우저 플레이 화면만 사용
- 16:9, 1080p 권장
- 마우스 커서는 포인터 잠금 상태로 숨김
- 불필요한 로딩과 메뉴 체류 시간 최소화
- 30~60초 범위 유지

## 권장 구성

| 시간 | 장면 | 전달할 핵심 |
| --- | --- | --- |
| 0~3초 | 타이틀과 작전 시작 | 게임 제목 |
| 3~6초 | God Mode 전장 전경 | A/B/C 3거점과 두 진영 |
| 6~9초 | 전차에 B 거점 명령 후 `Enter` | RTS 지휘 → 직접 조종 |
| 9~18초 | 이동과 일반·특수공격 | 직접 조종 전투와 블록 파괴 |
| 18~23초 | B/C 거점 교전과 점령 | 게임의 일차 목표 |
| 23~27초 | `G` 복귀, 다른 거점에 명령 | God ↔ Possession 반복 |
| 27~30초 | 거점 진영색과 점수 HUD | 점령 결과 |

## 녹화 전 확인

1. 브라우저 하드웨어 가속을 켭니다.
2. 다른 탭과 백그라운드 프로그램을 닫습니다.
3. 기본 1:1 Challenge를 사용합니다.
4. 소리가 녹음되는지 확인합니다.
5. 첫 촬영 전에 한 판 연습해 B 거점 전투 타이밍을 확인합니다.
