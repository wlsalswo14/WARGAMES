# 45초 플레이 영상 촬영안

## 촬영 원칙

- 실제 브라우저 플레이 화면만 사용
- 16:9, 1080p 권장
- 마우스 커서는 포인터 잠금 상태로 숨김
- 불필요한 로딩과 메뉴 체류 시간 최소화
- 30~60초 범위 유지

## 권장 구성

| 시간 | 장면 | 전달할 핵심 |
| --- | --- | --- |
| 0~4초 | 타이틀과 작전 시작 | 게임 제목 |
| 4~10초 | God Mode 전장 전경 | A/B/C 3거점과 두 진영 |
| 10~15초 | 전차 선택 후 `2` 명령 | RTS 지휘 |
| 15~20초 | `Enter`로 전차 빙의 | God ↔ Possession |
| 20~30초 | 이동과 좌클릭 일반공격 | 직접 조종 전투 |
| 30~37초 | 우클릭 특수공격으로 건물 또는 적 파괴 | 블록 파괴 |
| 37~42초 | `G` 복귀, 다른 유닛을 다른 거점에 명령 | 시점 반복 |
| 42~45초 | 거점 진영색 변경 또는 결과 HUD | 게임 목표 |

## 녹화 전 확인

1. 브라우저 하드웨어 가속을 켭니다.
2. 다른 탭과 백그라운드 프로그램을 닫습니다.
3. 기본 1:1 Challenge를 사용합니다.
4. 소리가 녹음되는지 확인합니다.
5. 첫 촬영 전에 한 판 연습해 B 거점 전투 타이밍을 확인합니다.
