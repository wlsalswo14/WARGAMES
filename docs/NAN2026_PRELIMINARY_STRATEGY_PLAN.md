## 1. 최종 방향

예선 통과나 우승을 보장할 수는 없다. 다만 현재 프로젝트는 단순한 3분 데모가 아니라, 여러 시스템이 서로 영향을 주는 **완결된 전쟁 게임**으로 발전시키는 편이 경쟁력이 높다.

최종 한 줄 소개는 다음과 같다.

> 7개 거점의 생산망과 분대를 지휘하고, 포격과 공습으로 전선을 연 뒤 결정적인 유닛에 직접 접속해 적 본부를 무너뜨리는 블록 전쟁 RTS/TPS.

핵심은 기능의 개수가 아니라 연결이다.

```text
거점 점령
→ 보급 수입 증가
→ 생산시설 건설
→ 생산 병과와 병력 상한 확장
→ 분대 대형과 지휘 능력으로 전선 돌파
→ 생산시설 또는 본부 파괴
→ 적 생산과 증원 약화
→ 최종 승리와 XP 획득
```

이 연결이 실제 플레이에서 보이면 WARGAMES는 흔한 슈팅 데모와 구분된다.

4. AI 도구, 주요 프롬프트, 활용 과정, 외부 에셋과 오픈소스를 담은 AI 기술 PDF
5. 2인 이상 팀일 때 팀원별 역할 PDF

GitHub Pages와 YouTube 링크는 심사 종료 시점까지 접근 가능해야 한다. 외부 에셋을 사용하면 출처와 라이선스를 AI 기술 문서에 명시해야 한다.

## 3. 현재 구현된 메인 게임

### 3.1 Conquest

- 제한 시간 12분
- 중립 거점 7개
- 청람과 적월의 1:1 전쟁
- 진영별 혼성 시작 병력 12기
- 지휘 본부와 전방 군수기지
- 거점·시설 기반 SUP 경제
- 전 거점 30초 장악, 적 본부 파괴, 적 전멸, 시간 종료 승리
- 결과에 따른 XP·계급·다음 경기 시작 보급 보너스

### 3.2 생산망

| 시설 | 생산 병과 | 전략 효과 |
| --- | --- | --- |
| 전방 군수기지 | 보병·전차·드론 | 기본 증원 유지 |
| 보병 막사 | 보병·장군 | 점령 병력과 지휘 유닛 |
| 기갑 공장 | 전차 | 돌파 전력과 병력 상한 |
| 전술 비행장 | 드론·헬기·전투기 | 공중 정찰과 강습 |

시설이 파괴되거나 연결 거점을 빼앗기면 해당 시설의 생산, 수입, 병력 상한 효과가 정지한다. 따라서 구조물 파괴는 장식이 아니라 전략 상태를 바꾼다.

### 3.3 부대 지휘

- `Tab`: 전술 커서와 자유 시점 전환
- 드래그: 여러 아군 유닛 선택
- 우클릭: 이동 또는 집중 공격
- `R`: 횡대·쐐기·종대 대형 변경
- `Enter`: 선두 유닛 직접 조종

대형별 목적은 명확해야 한다.

- 횡대: 넓은 화력선과 거점 포위
- 쐐기: 정면 돌파
- 종대: 좁은 시가지와 참호 통과

### 3.4 지휘 능력

| 키 | 능력 | 역할 |
| --- | --- | --- |
| `1` | 정밀 포격 | 밀집 병력과 방어선 해체 |
| `2` | 대전차 공습 | 폭격선을 따라 중장갑·건물 타격 |
| `3` | 긴급 증원 | 점령 거점에 보병 분대 투입 |
| `4` | 야전 수리 | 체력과 기동계·화기계 복구 |

각 능력은 SUP 비용과 재사용 대기시간을 가진다. 강력하지만 무한 반복할 수 없고, 생산과 지휘 능력 사이에서 자원 선택이 발생한다.

### 3.5 적 AI

적 AI는 다음 계층으로 행동한다.

1. 가까운 중립 또는 적 거점 배정
2. 이동 중 보이는 적 사격
3. 구조물 우회와 정지 탈출
4. 보유 시설을 분석해 부족한 생산시설 건설
5. 플레이어 소유 거점 우선 반격
6. 거점 3개 이상 확보 시 생산망 습격
7. 거점 5개 이상 확보 시 본부 공세
8. 드론의 자율 자폭과 중화기의 구조물 특수공격

AI는 외부 LLM이 아니라 브라우저에서 실행되는 경량 규칙·효용 시스템이다. GitHub Pages 서버에는 전투 연산 부하가 없다.

## 4. 보조 모드

### AI Challenge

- 3분
- A/B/C 거점 3개
- 1:1 또는 1:1:1
- 100 지휘 점수 선취
- 플레이어 명령 성향을 읽는 적응형 지휘관

짧은 심사 플레이와 영상 촬영에는 Challenge를 사용할 수 있다. 깊은 게임성을 확인하려는 심사자는 Conquest를 플레이한다.

### Sandbox

- 3개 진영과 자율 외교
- 무한 유닛·건물·생산시설 배치
- 산·참호 실시간 지형 제작
- 모든 유닛 직접 조종

Sandbox는 구현 범위와 기술력을 보여주는 보조 모드이며 메인 승리 루프를 대신하지 않는다.

## 5. 첫 3분 경험

### 0~20초

- 7개 거점과 양측 본부가 한 화면에 보인다.
- 장군 또는 전차가 자동 선택된다.
- HUD가 `거점 확보 → 생산시설 → 적 본부`를 안내한다.

### 20~60초

- 플레이어가 좌우 부대를 나눠 첫 거점을 점령한다.
- 중앙에서는 전차·공중 유닛 교전이 시작된다.
- 첫 점령으로 영토색과 SUP 수입이 바뀐다.

### 60~120초

- 플레이어가 첫 생산시설을 건설한다.
- 필요한 병과를 직접 생산한다.
- 적 AI도 점령 거점에 생산시설을 건설한다.

### 120~180초

- 첫 포격 또는 공습이 전선을 바꾼다.
- 플레이어가 전차·헬기·전투기에 직접 접속한다.
- 구조물 붕괴와 생산망 손실이 실제 증원 차이로 이어진다.

첫 3분 안에 지휘, 생산, 능력, 직접 조종, 파괴의 다섯 축을 모두 경험하게 하는 것이 목표다.

## 6. 재미와 반복 플레이

### 단기 보상

- 점령 시 영토색과 수입 즉시 변화
- 강한 특수탄과 지휘 능력의 큰 폭발
- 유닛·나무·건물의 블록 분해
- 장군 제거와 생산시설 파괴 알림

### 중기 선택

- 막사, 기갑 공장, 비행장 중 무엇을 먼저 지을지 선택
- 여러 거점을 넓게 방어할지 중앙을 돌파할지 선택
- SUP를 유닛, 건물, 지휘 능력 중 어디에 쓸지 선택
- God Mode에 남을지 직접 조종으로 전선에 개입할지 선택

### 장기 보상

- 경기 결과 XP
- 계급 상승
- 시작 보급 보너스
- 서로 다른 지휘 방식과 병과 조합 재도전

성장 보너스는 작게 유지해 실력보다 누적 플레이가 압도하지 않게 한다.

## 7. 유지보수 구조

| 파일 | 책임 |
| --- | --- |
| `ConquestSession.ts` | 시간, CP, 완전 장악, 승패 |
| `ConquestRuntime.ts` | 세션, 지휘 능력, 예약 타격, 결과 연결 |
| `ProductionCatalog.ts` | 생산 병과, 수입, 병력 상한 |
| `ProductionNetwork.ts` | 시설 배치, 가동 판정, 출격, AI 건설 |
| `CommanderAbilitySystem.ts` | 능력 비용과 재사용 대기시간 |
| `PlayerProgression.ts` | XP, 계급, 시작 보급 |
| `conquestLayout.ts` | 7거점 전장과 구조물 배치 |
| `BattlefieldAI.ts` | 유닛 전술 행동 |
| `NavigationSystem.ts` | 구조물 우회와 정지 탈출 |
| `CombatSystem.ts` | 발사체, 폭발, 광역 피해 |
| `BrickWarfare.ts` | 시스템 연결과 프레임 순서 |

새 규칙은 가능한 한 독립 시스템이나 데이터 모듈에 추가한다. `BrickWarfare.ts`에는 시스템 호출 순서와 사용자 이벤트 연결만 둔다.

## 8. 성능 예산

- Conquest 발사체 최대 96개
- 구조물은 재질별 `InstancedMesh`
- HUD 5Hz, 거점 판정 10Hz
- AI는 20Hz 이하의 고정 주기
- 파괴 유닛과 GPU 리소스 자동 정리
- 소프트웨어 렌더러 감지 시 내부 해상도 축소와 그림자 비활성화
- 경기 타이머와 물리가 같은 시뮬레이션 시간축 사용

하드웨어 가속이 켜진 브라우저는 WebGL을 GPU로 렌더링한다. GitHub Pages는 정적 파일만 전달하고 전투·AI·물리는 사용자 브라우저에서 실행한다.

## 9. 검증 결과

구현 단계에서 다음을 확인했다.

- TypeScript 전체 검사 통과

- 7개 목표 표시와 4개 지휘 능력 버튼 표시
- 포격 사용 시 SUP 차감, 순차 폭발, 재사용 대기시간 적용
- 60초 강제 시뮬레이션에서 양 진영 거점 점령
- 적 AI 생산시설 건설과 생산시설 파괴
- 플레이어 막사 건설과 장군 생산
- 드래그 다중 선택과 대형별 서로 다른 목적지
- Challenge 3거점 점수전 회귀 검증
- Sandbox 3진영, 무한 배치, 신규 생산시설 회귀 검증

## 10. 30~60초 영상 구성

영상은 기능 목록이 아니라 한 번의 반전을 보여준다.

1. 0~6초: 7개 전장과 양측 본부
2. 6~13초: 드래그 다중 선택과 쐐기 대형 진격
3. 13~20초: 거점 점령, 영토색과 수입 변화
4. 20~28초: 기갑 공장 건설과 전차 출격
5. 28~36초: 적 생산시설에 공습
6. 36~46초: 전투기 또는 전차 직접 조종
7. 46~55초: 건물 붕괴, 장군 또는 본부 타격
8. 55~60초: 결과 화면과 계급 XP

영상에는 개발 콘솔, 소프트웨어 렌더러 경고, 빈 지형 대기 장면을 넣지 않는다.
