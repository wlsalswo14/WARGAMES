# 게임 소개 및 실행 설명

## 1. 게임 기본 정보

- **제목:** PROJECT BRICK WARFARE
- **장르:** 블록 샌드박스 RTS / TPS / FPS 하이브리드 전장 시뮬레이터
- **한 줄 소개:** 무한히 생성되는 블록 전장을 지휘하고, 모든 진영의 유닛을 직접 조종해 전쟁의 흐름을 바꾸는 3D 전술 게임
- **플랫폼:** PC 웹 브라우저
- **플레이 링크:** `https://wlsalswo14.github.io/WARGAMES/`

## 2. 게임 목표

플레이어는 특정 국가에 소속되지 않은 전장 관찰자이자 개입자입니다. 신 모드에서 세 진영의 전력을 배치하고 명령하거나, 전장에 존재하는 유닛에 직접 빙의할 수 있습니다.

각 진영은 30기의 기본 전력으로 시작하며, 본부가 살아 있는 동안 전투 손실이 발생하면 다음 증원 주기에 30기까지 자동 보충됩니다.

주요 목표는 다음과 같습니다.

1. 맵 곳곳의 거점을 점령해 보급 수입과 증원 위치를 확보합니다.
2. 적대 진영의 병력과 구조물을 파괴합니다.
3. 적 지휘 본부의 지지 블록을 파괴해 본부를 붕괴시킵니다.
4. 변화하는 진영 관계와 AI 작전에 맞춰 전술을 변경합니다.

샌드박스 전장이라는 특성상 플레이어는 어느 진영을 지원할지 자유롭게 변경할 수 있습니다.

## 3. 플레이 방법

### 신 모드

- `WASD`: 전장 카메라 이동
- `Q`, `E`: 카메라 회전
- 마우스 휠: 카메라 확대 및 축소
- 전장 시작: 별도 화면 클릭 없이 직접 조종과 동일한 방식으로 마우스 포인터 자동 고정
- 화면 클릭: `Esc`로 해제한 마우스 포인터 다시 고정
- 마우스 이동: 포인터 고정 중 카메라 방향 및 고도 조절
- `Esc`: 마우스 포인터 고정 해제
- 유닛 좌클릭: 유닛 선택
- 지면 우클릭: 이동 명령
- 적 유닛 우클릭: 공격 명령
- 유닛 더블클릭 또는 선택 후 `Enter`: 직접 조종
- `F`: 배치할 진영 변경
- 화면 하단 버튼 또는 숫자키 `1`~`9`, `0`: 병력·방어물·지형 도구 선택
- 화면 하단 지형 버튼: 산 생성, 참호 굴착, 건물 및 나무 배치

### 직접 조종

- `W`, `S`: 마우스가 보는 방향을 기준으로 전진과 후진
- `A`, `D`: 마우스가 보는 방향을 기준으로 오른쪽과 왼쪽 이동
- 마우스 이동: 마인크래프트 방식의 방향 및 카메라 회전
- 마우스: 조준과 시점 이동
- 좌클릭: 무기 발사
- `Space`, `Ctrl`: 상승·하강 또는 전투기 기수 조작
- `V`: 1인칭과 3인칭 전환
- `G` 또는 `Esc`: 신 모드 복귀

## 4. 진영

### 청람 연방

기동 교리를 사용하는 세력입니다. 빠른 거점 확보와 유연한 병력 전환을 선호합니다.

### 적월 공화국

화력 교리를 사용하는 세력입니다. 전차를 집중해 한 전선을 돌파하는 작전을 선호합니다.

### 황토 방위령

참호 방어 교리를 사용하는 세력입니다. 거점을 방어하며 소모전을 유도합니다.

## 5. 유닛

- **보병:** 저렴하고 거점 점령이 가능하지만 장갑과 화력이 낮습니다.
- **전차:** 높은 체력과 장갑, 강력한 주포를 보유합니다. 측면과 후면은 상대적으로 취약합니다.
- **전투기:** 빠른 속도로 상공을 장악하지만 낮은 속도와 높은 받음각에서 실속할 수 있습니다.
- **공격 헬기:** 저고도 화력 지원에 적합합니다. 급격한 하강 시 와류고리 상태에 진입할 수 있습니다.
- **정찰 드론:** 측풍의 영향을 크게 받지만 저렴한 공중 정찰과 기습 공격에 유용합니다.

## 6. 외교 개입

AI 진영은 전력 격차와 거점 소유 상황에 따라 관계를 변경합니다. 신 모드 좌측 관계 패널의 `개입`을 선택하면 보급 자원을 사용해 동맹·중립·적대 관계를 강제로 변경할 수 있습니다.

신 모드의 유닛·장벽·참호 배치는 보급 자원을 소비하지 않으며 무제한입니다. 플레이어가 직접 격파한 유닛이나 빙의 중인 유닛이 파괴되면 전투 속도가 느려지고, 카메라가 폭발 위치를 확대해 브릭 분해 장면과 킬로그를 보여줍니다.

게임을 시작할 때 산악 교전지, 참호 전선, 시가 전장 중 하나가 무작위로 선택됩니다. 테마에 따라 산과 참호 위치, 건물 수와 배치, 지면 색조가 달라집니다.

신 모드의 지형 제작 도구는 클릭한 위치에 산악 고지를 만들거나 지면을 낮춰 참호를 굴착합니다. 건물과 나무 도구로 시가전 구역과 숲도 자유롭게 확장할 수 있습니다. 전장에는 11개 거점이 있으며, 거점을 점령할 때마다 주변 일정 범위의 실제 지형이 소유 진영 유닛과 동일한 청색·적색·황색으로 변합니다.

폭발 자체는 장식용 블록 파편을 만들지 않습니다. 유닛, 나무, 건물처럼 실제 브릭 대상이 파괴된 경우에만 해당 대상의 블록이 분해되어 튀어 나갑니다.

## 7. 실행 방법

### 웹 실행

Chrome, Edge, Firefox 등 WebGL 2를 지원하는 최신 데스크톱 브라우저에서 플레이 링크에 접속합니다. 별도의 로그인이나 유료 라이선스가 필요하지 않습니다.

### 소스 실행

```bash
git clone https://github.com/wlsalswo14/wargames.git
cd wargames
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`를 사용합니다. 결과물은 `dist` 디렉터리에 생성됩니다.

## 8. 권장 환경

- 데스크톱 Chrome 또는 Edge 최신 버전
- WebGL 2 지원 GPU
- 1366×768 이상 화면
- 키보드와 마우스
