# AI 활용 기술 문서

## 1. AI 활용 개요

PROJECT BRICK WARFARE는 다음 두 종류의 AI 활용을 포함합니다.

1. 게임 내부에서 실시간으로 작동하는 진영 지휘관 및 자율 외교 AI
2. 기획 구조화, 구현, 타입 검증과 브라우저 테스트 과정에서 사용한 생성형 AI 개발 지원

## 2. 게임 내부 AI 구조

### 2.1 진영 지휘관

각 진영은 독립적인 지휘관 상태를 보유합니다. 지휘관은 일정 주기로 다음 정보를 평가합니다.

- 생존 병력 수
- 전차와 항공 전력 비율
- 소유 거점 수
- 진영 고유 교리
- 현재 선택된 전략

평가 결과에 따라 다음 작전 중 하나를 선택합니다.

- 기갑 집중 돌파
- 전진 거점 확보
- 종심 방어
- 항공 우세 확보
- 참호 방어선 구축

선택된 작전은 증원 병과와 유닛의 목표 우선순위에 반영됩니다. 작전 변경 시 판단 이유가 HUD에 표시되므로 플레이어가 AI 의사결정을 확인할 수 있습니다.

### 2.2 유닛 전술 AI

각 유닛은 다음 순서로 행동을 결정합니다.

```text
플레이어 직접 조종 여부 확인
→ 신 모드 명령 확인
→ 외교 관계상 적대 유닛 탐색
→ 유효 사거리 및 선호 교전 거리 계산
→ 공격 또는 접근
→ 표적이 없으면 지휘관 전략에 맞는 거점 선택
```

유닛은 동맹이나 중립 진영을 자동 공격하지 않습니다. 외교 관계가 변경되면 기존 전투 대상도 다시 평가합니다.

### 2.3 자율 외교 AI

외교 시스템은 세 진영의 종합 전력을 비교합니다.

```text
종합 전력 =
생존 유닛 체력
+ 유닛 자산 가치
+ 소유 거점 가치
```

특정 진영이 지나치게 강해지면 약한 두 진영이 동맹을 체결하고 강한 진영을 적대할 가능성이 높아집니다. 전력 균형이 회복되면 동맹 해소, 휴전 또는 거점 분쟁이 발생할 수 있습니다.

모든 외교 관계는 대칭으로 적용됩니다.

## 3. 물리 기반 의사결정

### 장갑과 도탄

피격 방향과 유닛 전방 벡터의 내적을 이용해 전면·측면·후면 장갑 계수를 결정합니다. 입사각이 작고 관통력이 부족하면 도탄으로 처리합니다.

### 항공 역학

- 전투기: 추력, 속도 기반 양력, 받음각, 실속 조건
- 헬기: 지면과의 거리에 따른 지면효과, 고도에서 급하강할 때 와류고리 하강력
- 드론: 헬기보다 높은 측풍 영향 계수

실제 비행 인증용 시뮬레이터가 아니라 게임 플레이를 위한 축약 모델이며, 각 현상의 전술적 차이를 전달하는 데 목적이 있습니다.

### 구조물 붕괴

건물 하단 블록을 지지 블록으로 분류합니다. 생존 지지 블록 비율이 임계값 아래로 내려가면 상부 블록이 연쇄적으로 물리 파편으로 전환됩니다. 큰 붕괴는 주변 유닛에 폭발형 충격 피해를 전달합니다.

## 4. 생성형 AI 활용

### 사용 도구

- OpenAI Codex

### 활용 영역

- 대규모 기획을 브라우저 기술 데모 구조로 분해
- TypeScript 및 Three.js 프로젝트 구조 설계
- 유닛, 탄도, 전투, 절차 지형, 외교 시스템 코드 작성
- TypeScript 컴파일 오류 수정
- Playwright 기반 브라우저 로딩·상호작용·콘솔 오류 검증
- README 및 제출 문서 초안 작성

### 주요 지시 사항

사용자가 제공한 주요 지시의 핵심은 다음과 같습니다.

> 블록 비주얼의 RTS/TPS/FPS 하이브리드 전쟁 게임을 만들고, 신 모드와 모든 유닛 직접 조종, 절차 생성 맵, 거점, 실세계 물리 요소, 블록 파괴, 세 진영 자율 외교를 구현한다.

구현 과정에서 생성형 AI에는 다음 원칙을 추가로 적용했습니다.

- 외부 이미지나 3D 모델 없이 코드 기반 지오메트리를 사용한다.
- 별도의 서버와 유료 API 없이 브라우저에서 실행 가능해야 한다.
- 게임 내부 AI의 판단 근거를 HUD에 노출한다.
- TypeScript strict 모드와 프로덕션 빌드를 통과해야 한다.
- 실제 브라우저에서 시작, 병력 배치, 빙의, 이동, 사격, 신 모드 복귀를 검증한다.

### 검토 및 수정

생성된 코드는 다음 절차로 검토했습니다.

1. `npm run check`로 정적 타입 검사
2. `npm run build`로 프로덕션 빌드 확인
3. Chromium에서 WebGL 렌더링과 HUD 확인
4. 시작 버튼, 병력 배치, 유닛 선택, 직접 조종, 이동, 사격, 복귀 흐름 확인
5. 브라우저 콘솔 및 런타임 예외 확인

## 6. 한계와 향후 개선

현재 버전은 웹 브라우저에서 핵심 개념을 검증하기 위한 기술 데모입니다. 물리 계산은 실제 군사·항공 훈련용 모델이 아니라 플레이 감각과 전술 차이를 위한 축약 모델입니다.

향후에는 공간 분할을 통한 대규모 유닛 최적화, 개별 궤도 접지력, 구조 연결 그래프, 공력 계수 데이터화, 절차 생성 도심과 교량, 저장 가능한 전장 시드 기능을 추가할 예정입니다.
